# Limitations and deviations

The formal run does not use an interactive theorem prover. Its universal
evidence is a human-readable symbolic derivation whose algebraic core is
checked with exact rational arithmetic over several finite widths. The
arbitrary-width step is justified by pole order, not extrapolated from those
widths.

The sampled Jacobian audit uses dimensions 8 by 12 rather than a language
model. Scale is irrelevant to the universal proof and this audit is not
presented as full-scale training evidence.
